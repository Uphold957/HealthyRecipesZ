# 健康家常菜谱

## 软件简介

健康家常菜谱是一款面向 iOS 移动设备的清新风格菜谱应用，主打日常家庭常做菜与健康饮食搭配。

应用采用类似短视频平台的上下滑浏览方式，用户可以像刷视频一样快速切换不同菜品。每一道菜都以图文/视频感视觉、菜品描述、营养信息、食材清单和详细步骤呈现，帮助用户更直观地学习做法。

当前内容覆盖高蛋白、低脂、清淡汤品、便当主食等常见健康家常场景，适合日常晚餐、午餐便当和控脂饮食参考。

## 当前功能

- 支持上下滑分页浏览菜谱
- 每屏展示一道完整菜品
- 包含菜品标题、副标题、描述、食材和烹饪步骤
- 展示热量、蛋白质、用时、难度等健康信息
- 采用简洁清新的健康饮食视觉风格
- 使用 MVVM 架构拆分 Model、ViewModel 和 View，便于后续维护扩展
